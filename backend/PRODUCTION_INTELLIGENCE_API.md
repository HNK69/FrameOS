# Production Intelligence API & Integration Contract

## Overview

The Production Intelligence layer powers the agency/editor workflow and operational analytics. All endpoints enforce workspace tenancy via `current_identity` (using the HttpOnly `frameops_session` cookie or `Authorization: Bearer <token>`).

No database migrations are required; the implementation builds directly upon existing SQLAlchemy models while preserving data integrity and full provenance.

---

## Endpoints

### 1. Task Management

#### `GET /api/tasks`
List and filter production tasks with full editor feedback audit logs, immutable AI recommendations, and latest corrections.

**Query Parameters:**
- `project_id` (optional `int`): Filter by project.
- `client_id` (optional `int`): Filter by client.
- `status` (optional `str`): Filter by status (`pending`, `in_progress`, `completed`, `blocked`, `accepted`, `rejected`, `all`).
- `priority` (optional `str`): Filter by priority (`low`, `medium`, `high`, `urgent`).
- `category` (optional `str`): Filter by category (`cut`, `color`, `audio`, `vfx`, `graphic`, `general`).
- `search` (optional `str`): Substring search over title and instruction.

**Response `200 OK`:**
```json
[
  {
    "id": 1,
    "project_id": 10,
    "client_id": 4,
    "run_id": 2,
    "title": "Color grade adjustment for brand consistency",
    "category": "color",
    "instruction": "Adjust color grading on hero shots to warm golden tone per client feedback.",
    "original_recommendation": "Use high contrast grade.",
    "latest_correction": "Adjust color grading on hero shots to warm golden tone per client feedback.",
    "resolve_workflow": "Apply LUT in DaVinci Resolve",
    "priority": "high",
    "status": "in_progress",
    "confidence": 0.95,
    "requires_confirmation": false,
    "feedback_count": 2,
    "created_at": "2026-11-14T12:00:00Z"
  }
]
```

#### `GET /api/tasks/{task_id}`
Retrieve a single task with full detail, including source processing run excerpt and complete feedback history.

#### `PATCH /api/tasks/{task_id}`
Update task status, priority, or instruction. When an instruction, title, workflow, or priority is modified, provenance is preserved by appending an entry to `Feedback` with the editor's `author_id`, UTC timestamp, and original AI prompt.

**Request Body (`TaskUpdateInput`):**
```json
{
  "status": "completed",
  "priority": "urgent",
  "instruction": "Shorten intro logo reveal to 2.5 seconds.",
  "correction_note": "Approved during morning review.",
  "knowledge_type": "client_confirmed",
  "client_confirmed": true
}
```

### 2. Asset Intelligence

#### `GET /api/projects/{project_id}/asset-intelligence`
Returns verified assets and transcript-extracted asset requirements. Enforces evidence-based statuses verified against physical disk storage:
- `Present`: File exists on disk with non-zero byte size.
- `Missing`: Referenced in transcript/brief or registered in database with missing file on disk.
- `Unknown`: Asset record exists with no storage path.
- `Unverified`: File path exists in DB but has not been verified.

**Response `200 OK`:**
```json
{
  "project_id": 10,
  "summary": {
    "total": 6,
    "present": 4,
    "missing": 1,
    "unknown": 1,
    "unverified": 0,
    "coverage_percentage": 66.7
  },
  "assets": [
    {
      "id": 101,
      "name": "Brand_Logo_Vector.svg",
      "category": "logo",
      "status": "Present",
      "storage_verified": true,
      "size_bytes": 48200
    }
  ],
  "extracted_requirements": []
}
```

### 4. Adaptive Knowledge & Memory Integration

#### `GET /api/clients/{client_id}/adaptive-knowledge`
Categorizes client knowledge into:
- `ai_recommendation`: Generated by OpenClaw/Groq.
- `editor_correction`: Editor interventions.
- `client_confirmed`: Confirmed by client.
- `project_specific`: Bounded to a single project.
- `reusable_client_knowledge`: Generalizable cross-project preferences.

#### `POST /api/clients/{client_id}/adaptive-knowledge`
Record a new verified client rule or preference directly into the memory stream.
